# 50 Git Workflow & Commit Rules

## Branch Rules

- Always inspect `git status` before beginning work.
- Never commit or modify files directly on `main`.
- Stay strictly within the scope of the assigned branch.

## Commit Guidelines

- Use focused Conventional Commits (`feat:`, `fix:`, `chore:`, `docs:`, `test:`, `ci:`).
- Break large feature additions into multi-commit logical steps.
- Never commit secrets, `.env.local` files, or real student personal data.
- Never auto-merge branches into `main`.
- Stop and report commit hashes and status upon completing the branch scope.
