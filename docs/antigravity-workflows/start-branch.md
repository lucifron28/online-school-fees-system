# Start Branch Workflow

Use this workflow when beginning a new feature or task branch in Antigravity.

## Instructions
1. **Inspect Repository:** Check `git status` and `git branch`. Confirm working tree is clean.
2. **Sync Main:** Checkout `main`, pull latest changes from remote.
3. **Create Branch:** Create and switch to the requested feature/chore branch (e.g. `feat/auth-rbac`).
4. **Read Rules:** Read `.agents/rules/*.md` and existing project documentation.
5. **Formulate Implementation Plan:** Produce an implementation plan covering existing state, files to create/modify, packages to install, verification approach, and proposed commits.
6. **Seek User Approval:** Stop and wait for user confirmation before editing files.
